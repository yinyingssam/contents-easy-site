# 콘텐츠 이지 디자인 규칙

이 사이트의 디자인 기준이다. 내용 기준은 `docs/PRD.md`, 디자인 기준은 이 문서다. 둘이 다르면 사용자에게 먼저 묻는다.

- 레퍼런스 캡처: `docs/design/reference-lumina.png` (Lumina SaaS 랜딩 페이지)
- 로고: `docs/design/logo.png` (로고 글자는 "컨텐츠 이지", 사이트 글에는 **"콘텐츠 이지"**로 쓴다)

## 1. 목표 느낌

깔끔하고 **신뢰감 있는** 네오 브루탈리즘. 또렷한 테두리와 흐림 없는 그림자로 개성을 주되, 장난스럽거나 촌스러워 보이지 않게 절제한다.

## 2. 색상 (이 값만 쓴다)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 딥 남색 | `#13245A` | 첫 화면 등 큰 배경, 어두운 카드 |
| 로고 남색 | `#1F3B7B` | 테두리, 그림자, 제목, 본문 글자 |
| 진한 민트 | `#2EE6BE` | **누르는 버튼**("강의·컨설팅 신청하기" 등, 남색 글씨 + 남색 테두리)과 **첫 화면 제목의 "쉽게" 글자** 두 곳에만 |
| 연한 민트 | `#E3FAF4` | 카드 바탕, 강조 구역 배경, 선택된 칸 바탕 |
| 하늘색 | `#5CC8FF` | 아이콘, 남색 배경 위 그림자, 선택된 탭 그림자 |
| 연한 하늘 화이트 | `#F1F7FF` | 밝은 구역 배경 |
| 흰색 | `#FFFFFF` | 카드 바탕, 남색 배경 위 글자 |

CSS는 `:root`에 변수로 정의하고 값은 변수로만 쓴다.

비율: 남색·흰색 70% · 연한 하늘·연한 민트 20% · 진한 민트+하늘 10% 이하.

규칙: **진한 민트 = 누르는 것 + 첫 화면 "쉽게".** 손님 눈이 "쉽게"에서 신청 버튼으로 이어지도록, 진한 민트는 이 두 곳 말고는 쓰지 않는다. (사용자가 고른 방식. 흰 글자 + 하늘색 그림자, 하늘색 글자, 노랑은 써 보고 뺐다)

하지 않는 것:
- 진한 민트를 다른 글자, 그림자, 장식, 배경에 쓰기
- 오렌지 쓰기 (오렌지는 로고의 재생 버튼에만 있다. 사이트에서는 쓰지 않는다)
- 그라데이션, 빛 번짐(glow), 네온 효과
- 검정 `#000` 테두리 (테두리와 그림자는 로고 남색)

## 3. 네오 브루탈리즘 요소 (레퍼런스에서 가져올 것)

- 테두리: 2px solid 로고 남색
- 그림자: 흐림 없는 그림자 `4px 4px 0` (6~8px처럼 크게 하지 않는다)
  - 밝은 구역: 그림자 색은 로고 남색
  - 남색 구역: 흰 카드에 하늘색 그림자 (남색 위 민트 버튼도 하늘색 그림자)
- 모서리: 카드·버튼 8~12px 둥글게, 작은 뱃지는 알약 모양
- 배경: 레퍼런스처럼 아주 옅은 점 패턴은 써도 된다 (남색 배경이면 흰 점 투명도 8% 이하)
- 버튼을 누르거나 올리면 그림자가 줄고 버튼이 그만큼 내려앉는 움직임 하나만. 섹션마다 떠오르는 애니메이션은 넣지 않는다

## 4. 글자

- 한글 글꼴: Pretendard (굵기 400·600·800). 제목은 800, 본문 400
- 첫 화면 제목은 아주 크고 굵게(레퍼런스처럼), 줄 간격은 좁게. 핵심 단어 "쉽게" 하나만 진한 민트(버튼과 같은 색). 그림자·외곽선·빛 번짐은 넣지 않는다
- 본문 16px 이상, 한 줄 40자 안팎
- 영어 대문자 라벨, 가운뎃점(·)으로 잇는 장식 문구는 만들지 않는다

## 5. 첫 화면 구성 (레퍼런스 구조를 콘텐츠 이지에 맞게)

| 레퍼런스 | 콘텐츠 이지 |
|---|---|
| 노란 배경 | 딥 남색 배경 |
| 왼쪽 "NEW" 뱃지 | 흰 테두리 알약 뱃지 하나 (사용자가 준 문구만. 없으면 빼기) |
| 큰 영어 제목 | PRD 10번의 한 문장 후보 중 하나. 핵심 단어 하나만 진한 민트 |
| 설명 한두 줄 | 하는 일: AI 교육 · 영상 제작 · SNS 브랜딩 강의와 컨설팅 |
| 검정 버튼 + 흰 버튼 | 진한 민트 "강의·컨설팅 신청하기" + 흰 테두리 보조 버튼(예: "강의 내용 보기") |
| 버튼 아래 체크 문구 | "가격은 문의 후 안내" 등 사실만 |
| 오른쪽 매출 대시보드 카드 | **세 서비스 카드**(AI 교육 / 영상 제작 / SNS 브랜딩) 또는 실제 영상 썸네일 카드 |
| "Just signed up" 떠 있는 카드 | 빼기 (지어낸 사람·숫자 금지) |

위쪽 메뉴: 로고(흰 상자 안, 하늘색 그림자) · 하는 일 · 강의 내용 · 경력과 사례 · 후기 · 오른쪽 끝 진한 민트 신청 버튼.

## 6. 지어내지 않기

- 매출, 수강생 수, 만족도, 후기, 사람 이름, 출강 기관을 지어내지 않는다. PRD에 "준비 중"이면 자리만 만들고 "준비 중"으로 둔다
- 레퍼런스의 "14-day free trial", "No credit card required" 같은 문구는 쓰지 않는다

## 7. 품질 기준

- 폰 화면 우선. 375px 폭에서 가로 스크롤 없음
- 키보드로 이동하면 초점 테두리가 보인다 (밝은 구역은 남색 2px, 남색 구역은 하늘색 2px)
- `prefers-reduced-motion`이면 움직임을 끈다
- 남색 위 글자는 흰색, 민트 버튼 글자는 딥 남색 (둘 다 대비 충분)
