# 사이트 설계도(PRD) — 콘텐츠 이지

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
콘텐츠 이지는 AI 교육, 영상 제작, SNS 브랜딩 강의와 컨설팅을 하는 곳이다.
손님 동선: 인스타·유튜브·블로그·SNS·소개로 찾아온 사람이 → 강의·컨설팅·협업 사례를 보고 → 필요한 신청을 남긴다.

## 2. 손님
- 누가: 아래 세 부류 모두
  - 기업·기관 담당자 (직원 교육 강의를 맡길 회사, 공공기관, 학교)
  - 소상공인·1인 사업자 (SNS 브랜딩·영상 컨설팅이 필요한 사장님)
  - 개인 수강생 (AI·영상 제작을 배우고 싶은 개인)
- 어디서 알고 오나: 인스타그램, 유튜브, 블로그·SNS, 지인 소개

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 강의·컨설팅 내용 (무엇을 배우고 어떤 결과를 얻는지, 커리큘럼)
2. 진행 방식·일정 (출강/온라인, 시간, 인원, 기간)
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
아래 항목을 넣는다. 내용은 사용자가 준 그대로만 쓰고, 받기 전에는 "준비 중"으로 둔다.
- 아이템별 커리큘럼 (AI 교육 / 영상 제작 / SNS 브랜딩): 준비 중
- 경력: 준비 중
- 자격증: 준비 중
- 출강한 곳: 준비 중
- 협업 사례: 준비 중
- 후기: 실제 수강 후기가 있음. 받은 원문 그대로 넣는다 (지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 강의·컨설팅 신청하기
- 누르면: 신청 폼

## 6. 페이지 구성 (위에서 아래로)
한 페이지로 만든다.
1. 첫 화면 — 한 문장 + "강의·컨설팅 신청하기" 버튼
2. 하는 일 세 가지 — AI 교육 / 영상 제작 / SNS 브랜딩 (강의·컨설팅·협업)
3. 아이템별 커리큘럼 — 무엇을 배우고 어떤 결과를 얻는지
4. 진행 방식·일정 — 출강/온라인, 시간, 인원, 기간 (사용자가 준 내용만)
5. 믿을 수 있는 이유 — 경력 · 자격증 · 출강한 곳 · 협업 사례
6. 후기 자리 (실제 후기를 받으면 넣음)
7. 신청 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 신청 종류: 강의 / 컨설팅 / 협업 중 하나 고르기
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 문의 후 안내 (사이트에 가격은 적지 않는다)
- 시간: (미정)
- 위치·진행 방식: (미정)
- 연락 방법: (미정) — 인스타그램·유튜브·블로그 주소, 이메일 등 공개할 것을 받으면 넣는다

## 9. 이번에 넣지 않을 것
- 결제
- 회원가입·로그인
- 블로그·칼럼 (사이트 안 글쓰기. 외부 블로그 링크는 넣을 수 있음)

## 10. 첫 화면 한 문장 후보
1. AI와 영상으로 내 브랜드를 직접 알리는 법, 콘텐츠 이지가 알려 드려요.
2. AI 교육부터 영상 제작, SNS 브랜딩까지 강의와 컨설팅으로 함께해요.
3. 콘텐츠가 어렵다면, 콘텐츠 이지와 쉽게 시작하세요.

## 11. 다음에 할 것
- 증거 칸(커리큘럼·경력·자격증·출강한 곳·협업 사례·후기) 실제 내용 채우기
- 진행 방식·일정, 연락 방법 확정
- 결제, 회원가입·로그인, 블로그·칼럼은 필요해지면 다시 검토

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 + 신뢰감 · 참고 디자인: Lumina SaaS 랜딩 페이지(네오 브루탈리즘) — 구조만 참고하고 그대로 베끼지 않음
  - 캡처: docs/design/reference-lumina.png · 로고: docs/design/logo.png
  - 자세한 디자인 규칙: 이 폴더의 `contents-easy-design` 스킬(.claude/skills/contents-easy-design/SKILL.md)
- 색상 (유튜브 채널 남색 + 민트·하늘. 오렌지는 쓰지 않음)
  - 딥 남색 `#13245A` — 첫 화면 등 큰 배경
  - 로고 남색 `#1F3B7B` — 테두리, 그림자, 제목
  - 진한 민트 `#2EE6BE` — "강의·컨설팅 신청하기" 등 누르는 버튼에만
  - 연한 민트 `#E3FAF4` — 카드 바탕, 강조 구역 배경
  - 하늘색 `#5CC8FF` — 핵심 단어 "쉽게"의 그림자(글자는 흰색), 아이콘, 남색 위 그림자
  - 연한 하늘 화이트 `#F1F7FF` — 밝은 구역 배경
  - 흰색 `#FFFFFF` — 카드 바탕
  - 비율: 남색·흰색 70% · 연한 하늘·연한 민트 20% · 진한 민트+하늘 10% 이하
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 신청 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
